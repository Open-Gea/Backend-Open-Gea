# Documentation

- **API Documentation**: Each endpoint must be documented in a separate Markdown file under `docs/` with method, description, authentication, request/response examples, and curl command.
- **Inline Comments**: Use JSDoc/TSDoc for public functions; explain **why** non‑obvious code exists.
- **README & CONTRIBUTING**: Keep `README.md` and `CONTRIBUTING.md` up‑to‑date with project standards.
